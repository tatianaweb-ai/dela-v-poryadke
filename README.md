# Дела в порядке

MVP-трекер задач и проектов. Все данные хранятся в LocalStorage браузера — бэкенд и база данных не нужны.

## Стек

- Next.js 16 (App Router, Turbopack) + React 19 + TypeScript
- Tailwind CSS 4
- lucide-react (иконки)
- LocalStorage (единственное хранилище)

## Запуск

```bash
npm install
npm run dev      # http://localhost:3000
```

Продакшн-сборка:

```bash
npm run build
npm run start
```

Проверки:

```bash
npm run lint     # ESLint
npx tsc --noEmit # типы
```

## Возможности

**Авторизация.** Одно поле «Ваше имя» и кнопка входа. Имя кладётся в LocalStorage, кнопка «Выйти» в шапке удаляет сессию. Регистрации с паролем нет — она осознанно вне рамок MVP.

**Дашборд.** Приветствие по имени, карточки статистики (проекты / активные задачи / выполнено / просрочено), блок «Ближайшие дедлайны» с подсветкой просроченных и срочных задач, прогресс по активным проектам.

**Проекты.** Создание, редактирование, удаление (вместе с задачами проекта), прогресс-бар и ближайший дедлайн по каждому проекту. Кнопка «Открыть задачи» переключает список задач на этот проект.

**Задачи.** Создание, редактирование, удаление, чекбокс выполнения с зачёркиванием. Поиск по названию задачи и проекта, фильтры (все / активные / просроченные / выполненные), фильтр по проекту, сортировка по дедлайну, дате создания и названию.

**Статусы.** Просрочено / Сегодня / Скоро (до 3 дней) / Запланировано / Выполнено — цветовой индикатор и текстовая плашка, плюс относительная подпись там, где она уточняет сдвиг («Завтра», «Через 3 дня», «2 дня назад»). Правило «показывать подпись только если она не повторяет бейдж» держится в одном компоненте `RelativeDeadline`.

**Демо-данные.** При первом запуске, если хранилище пустое, создаются 2 проекта и 5 задач (в том числе просроченная и задача на сегодня), чтобы интерфейс не был пустым.

## Структура

```
src/

    layout.tsx          # корневой layout, шрифт, метаданные
    page.tsx            # единственная страница приложения
    globals.css         # Tailwind + анимации + базовые стили
  components/
    Providers.tsx       # провайдеры + заглушка до чтения LocalStorage
    AppShell.tsx        # переключение вкладок, модалки, выход
    AuthScreen.tsx      # экран входа по имени
    Header.tsx          # логотип, навигация, профиль
    Dashboard.tsx       # статистика, дедлайны, прогресс проектов
    StatCards.tsx       # карточки статистики
    ProjectList.tsx     # список проектов
    TaskList.tsx        # список задач, поиск, фильтры, сортировка
    TaskItem.tsx        # одна задача: чекбокс, дедлайн, edit/delete
    TaskModal.tsx       # форма создания/редактирования задачи
    ProjectModal.tsx    # форма создания/редактирования проекта
    Logo.tsx
    ui/                 # Button, Input, Modal, Toast, ConfirmDialog, ...
  context/
    AppStore.tsx        # состояние приложения + CRUD-операции
  hooks/
    useLocalStorage.ts  # SSR-безопасная обёртка над LocalStorage
  lib/
    date.ts             # работа с датами, статусами и склонениями
    seed.ts             # демо-данные
    validators.ts       # валидация форм и десериализация
    storage-keys.ts     # ключи LocalStorage
    cn.ts
  types/
    index.ts
```

## Как устроено хранение

`useLocalStorage` построен на `useSyncExternalStore`:

- сервер и гидратация всегда отдают начальное значение, поэтому разметка совпадает и ошибок гидратации нет;
- после монтирования читается реальное значение, о готовности сообщает флаг `isReady`;
- разобранные значения кэшируются, чтобы снапшоты сравнивались по ссылке;
- битый JSON не ломает приложение — значение откатывается к начальному, в консоль пишется предупреждение;
- изменения из другой вкладки подхватываются через событие `storage`.

## Ограничения MVP

Один пользователь на браузер, без сервера: очистка данных сайта удаляет проекты и задачи, обмена между устройствами нет. Нет ролей, приглашений, вложений, повторяющихся задач, email/push-уведомлений и восстановления пароля.
